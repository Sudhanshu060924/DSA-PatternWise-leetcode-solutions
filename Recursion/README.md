# 🔁 Recursion

This folder contains problems solved using recursion, a technique where a function calls itself to break down a problem into smaller subproblems.

## 📌 When to Use Recursion

- Tree traversal
- Backtracking
- Divide and conquer
- Problems with repeated structure

## 🧠 Core Idea

Recursion solves a problem by solving smaller instances of the same problem and combining results.

## 🚀 Common Patterns

- Recursion on trees
- Permutations and combinations
- Sequence generation
- Simple base case + recursive step

## 📚 Included Problems

- Sequential Digits
- Letter Combinations of a Phone Number
- Combination Sum
- Permutations
- Fibonacci Number

## ⏱️ Complexity

- Time and space vary by problem; recursive solutions often use **O(n)** stack depth for linear recursion.

---

## 💡 Tip

Always define a clear base case and ensure each recursive call moves toward it.
