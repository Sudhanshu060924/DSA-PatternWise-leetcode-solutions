# 🧠 Heap / Priority Queue

This folder contains problems that use a **heap** or **priority queue** to manage ordered data efficiently.

## 📌 When to Use Heaps

- Find top K elements
- Merge sorted lists
- Manage dynamic priority order
- Solve scheduling and frequency problems

## 🧠 Core Idea

A heap allows fast retrieval of the minimum or maximum element, usually in **O(log n)** time for insert and remove.

## 🚀 Common Uses

- Top K frequent elements
- Merge k sorted lists
- Task scheduling
- Finding closest points

## 📚 Included Problems

- Kth Largest Element in an Array
- Merge k Sorted Lists
- Top K Frequent Elements
- IPO
- Task Scheduler
- Top K Frequent Words
- Reorganize String
- K Closest Points to Origin

## ⏱️ Complexity

- Time: **O(n log n)** in most heap-based solutions
- Space: **O(n)** for heap storage

---

## 💡 Tip

Use `PriorityQueue` in Java and choose min-heap or max-heap based on the problem.
