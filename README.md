# 🚀 DSA Pattern-Wise LeetCode Solutions

This repository contains **Data Structures & Algorithms (DSA) patterns** implemented in Java, along with explanations and LeetCode-inspired problem examples.

The goal of this project is to help:

- 📚 Understand core DSA patterns
- ⚡ Improve problem-solving skills
- 🎯 Prepare for coding interviews
- 🧠 Recognize patterns instead of memorizing solutions

---

## 📂 Project Structure

Each folder represents a DSA concept or problem type and includes relevant Java solutions.

- 🔁 `2-Pointer`
- 🧩 `Basic Problems`
- 🔎 `Binary Search`
- 📊 `Dynamic Programing`
- 🌐 `Graph`
- 🗂️ `HashMap`
- 🧠 `Heap`
- 📈 `Kaden's algorithm`
- 🔁 `LL`
- 🧩 `Merge Intervals`
- 📘 `Prefix Sum`
- 🔁 `Recursion`
- 🪟 `Sliding-Window`
- ⚡ `Slow & Fast Pointer`
- 📚 `Stack Pattern`
- 🌲 `Tree`

Each folder may contain:

- 📖 Concept explanation
- 🧠 Intuition and pattern notes
- ⚙️ Approach and steps
- ⏱️ Complexity analysis
- 💻 Java code examples

## 🧩 Why Pattern-Based Learning?

Solving problems by pattern helps you:

- Identify **similar problem structures** faster
- Choose the right algorithm more reliably
- Reduce interview thinking time
- Reuse proven techniques across problems
