# 🌲 Tree Traversal

This folder contains binary tree traversal problems and Java implementations for standard traversal orders.

## 📌 Traversal Types

- **Level Order** (BFS)
- **Zigzag Level Order**
- **Preorder**
- **Inorder**
- **Postorder**

## 🚀 Included Problems

- Binary Tree Level Order Traversal
- Binary Tree Zigzag Level Order Traversal
- Binary Tree Level Order Traversal II
- Binary Tree Preorder Traversal
- Binary Tree Postorder Traversal
- Binary Tree Inorder Traversal

## 🧠 Core Concepts

- Use a queue for BFS/level order
- Use recursion or stack for DFS/preorder/inorder/postorder
- Track node order carefully for each traversal type

## ⏱️ Complexity

- Time: **O(n)** for each traversal
- Space: **O(n)** in the worst case for queue or recursion stack

---

## 💡 Tip

Understand the difference between preorder, inorder, and postorder before implementing.
