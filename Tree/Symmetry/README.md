# 🌲 Tree Symmetry & Subtree Problems

This folder contains tree problems related to symmetry, structure checks, and subtree comparisons.

## 📌 Key Ideas

- Compare nodes recursively
- Check mirror structure
- Invert tree links
- Match subtree structure and values

## 🚀 Included Problems

- Same Tree
- Symmetric Tree
- Invert Binary Tree
- Subtree of Another Tree

## 🧠 Common Techniques

- Depth-first search (DFS)
- Recursion with base cases
- Comparing left and right branches

## ⏱️ Complexity

- Time: **O(n)** for tree traversal
- Space: **O(h)** recursion stack

---

## 💡 Tip

For symmetry problems, compare the left subtree against the right subtree in mirrored order.
