# 🌲 Tree Algorithms

This folder contains Java solutions for common binary tree problems and tree traversal patterns.

## 📌 What to Expect

- Binary tree traversal
- Tree construction
- Depth and height calculations
- Path sum checks
- Lowest common ancestor
- Tree validation and recovery

## 🧠 Core Concepts

- **DFS**: preorder, inorder, postorder
- **BFS**: level order traversal
- **Recursion** for tree processing
- **Divide and conquer** on tree nodes

## 🚀 Included Problems

- Maximum Depth of Binary Tree
- Construct Binary Tree from Preorder and Inorder Traversal
- Construct Binary Tree from Inorder and Postorder Traversal
- Balanced Binary Tree
- Minimum Depth of Binary Tree
- Path Sum
- Path Sum II
- Lowest Common Ancestor of a Binary Search Tree
- Lowest Common Ancestor of a Binary Tree
- Diameter of Binary Tree
- Search in a Binary Search Tree
- Check Completeness of a Binary Tree
- Validate Binary Search Tree
- Recover Binary Search Tree

## 📚 Subfolders

- `Symmetry`: Same Tree, Symmetric Tree, Invert Binary Tree, Subtree of Another Tree
- `traversal`: Level order, Zigzag, Preorder, Inorder, Postorder traversals

## ⏱️ Complexity

- Time: **O(n)** for most tree traversals
- Space: **O(h)** for recursion stack, where `h` is tree height

---

## 💡 Tip

Trees are best solved by choosing the right traversal and carefully managing recursive calls.
