# 📊 Dynamic Programming

This folder is reserved for **Dynamic Programming (DP)** solutions and patterns.

## 📌 What is Dynamic Programming?

Dynamic Programming is a technique for solving problems by breaking them down into smaller overlapping subproblems and storing results to avoid repeated work.

## 🧠 Core Concepts

- **Memoization** (top-down)
- **Tabulation** (bottom-up)
- **State definition**
- **Transition relations**

## 🚀 Why DP?

Use dynamic programming when:

- The problem has overlapping subproblems
- The problem has an optimal substructure
- A naive recursive solution repeats work
