# 🌐 Graph Algorithms

This folder contains graph-based problems and Java solutions for common graph patterns.

## 📌 When to Use Graph Techniques

- Problems involving nodes and edges
- Connectivity and traversal
- Grid exploration
- Shortest path and component counting

## 🧠 Core Ideas

- **Depth-First Search (DFS)**
- **Breadth-First Search (BFS)**
- **Visited tracking**
- **Graph representation**

## 🚀 Example Pattern

For grid or matrix problems, treat each cell as a graph node and traverse neighbors using DFS or BFS.

## 📚 Included Problems

- Number of Islands

## ⏱️ Complexity

- Time: **O(n \* m)** for grid traversal problems
- Space: **O(n \* m)** for visited tracking

---

## 💡 Tip

Start with a clear graph model and choose the traversal method that matches the problem requirements.
